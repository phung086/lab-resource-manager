# UI/UX Style Guideline

This folder is reserved for visual guidelines, screenshots, design references,
and style decisions.

Current baseline:

- Operational internal tool.
- Vietnamese-first user-facing copy where practical.
- Clear role-aware navigation.
- Real data and explicit unavailable/no-data states.
- Accessible forms, tables, modals, focus states, and keyboard flows.

Do not add purely decorative redesigns ahead of required graduation workflows.
